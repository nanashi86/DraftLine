# Changelog

All notable changes to DraftLine are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Tips for six easy-to-miss tools, each shown once, when it would help: **Import Scenes** (8+ scenes or 10+ pages, no scene cards yet), **Analyze Value Shifts** (scene cards, none with a Value Shift), **Populate Bio** (3+ characters whose introductions would fill an empty bio field), the **Format stepper** (5+ findings), the **Dialogue spotlight** (3+ speaking characters, 20+ speeches) and **Plan** (90+ pages). A small pulsing dot marks **Split** or **Characters** (or the **Bios** / **Dialogue** tab when Characters is open on the other); a card beside the tool gives two sentences, the tool's own button (**Spotlight MARIE** names your top speaker) and **Got it**; tools always on screen get the card straight away, flipped above the status bar with its notch pointing down. It never takes focus, runs nothing without a click, returns the cursor to the script after Import Scenes or Populate Bio, and waits for a calm moment (3 s after typing, a minute after a script opens; not in Focus, Plan, Viewing or under another corner card). It never overlaps anything: it hides while its tool is covered (a drawer, a dialog) or a menu, dropdown, hover card or toast would overlap it, and steps aside as soon as its button opens the tool. One new tip per session (Analyze may follow Import). Using a tool any way, even before its tip showed, ends its tip; states are saved per browser (`draftline_hints`). **⋮ → About DraftLine → Tips → Show tips again** brings them back. Reduced motion turns off the pulse and slide.
- Story Bible → DNA → Glossary: a third section, **Screenplay Format**, with 19 terms. The page's elements come first, in the order they appear: Scene Heading (Slugline), Action, Character Cue, Dialogue, Parenthetical (Wryly), V.O. / O.S. / O.C., (CONT'D), (MORE), Dual Dialogue, Transition. Then, A–Z: Beat, Insert, Intercut, Montage / Series of Shots, One Page One Minute, Page Eighths, Pre-lap, Spec Script, Super. Like every glossary term they start as DraftLine's **starter** wording and can be replaced with your own. In the Format Doctor, a finding's chip (Scene heading format, Dangling parenthetical, Character cue without dialogue…) now opens the term that explains it, marked with a small book icon. The **starter** and **yours** badges explain themselves on hover, and the User Guide now walks through replacing a definition with your own.
- File → Final Draft opens **Export Final Draft**, with **Include margin notes (as Final Draft Script Notes)**. Checked, every margin note goes into the .fdx as a Final Draft `<ScriptNote>` on its element (multi-line notes kept line by line, notes in dual dialogue on their speech, a note on an empty line keeping that line), with the Script Note definition Final Draft keys them to. It's off by default, since margin notes are private, and the dialog says how many notes the script has (disabled with none). Saved per script as `fdxIncludeNotes`, in the library, backups and snapshot files; exporting another script from Projects follows that script's setting. Unchecked, the .fdx is byte for byte what it was before. Imported Script Notes still become margin notes, so notes now round-trip.
- User Guide: a **Final Draft (.fdx)** section under Export & Deliverables, with **What doesn't carry over to Final Draft**: 12A / locked scene numbers (renumbered 1, 2, 3…), Shot / act-break / Lyrics / Cast List elements (become Action), and Final Draft's own settings (SmartType, page layout, element settings, revision colours, All Caps display).
- Plan: a scene filter in the top bar's empty middle on Breakdowns and Stripboard: **Find scenes…** (heading, location, speaking character, or an exact scene number; capitals and accents ignored), **INT | EXT** and **DAY | NIGHT** (INT./EXT. counts as both). While set it shows **5 of 53 scenes ✕**, and the summary line counts scenes and pages shown. It closes with a divider like Write's Element · B I U S group, moves to the top of the Plan page under 1500px, only hides scenes (exports and Reports cover the whole script), and clears when another script opens.
- Characters → Dialogue: in a cast of more than 15 speakers, the character pills fold after the 12 with the most lines, behind a dashed **+N more** pill (**Show fewer** folds them again; the choice is remembered), so the stats and speeches stay near the top. A picked character in the fold stays shown, lit, after the top 12.
- Characters → Dialogue: the **monologues** count is now a toggle. On, the speech list keeps only that character's monologues (over 5 printed lines or 60 words), each tagged **Monologue · N lines**, with Go ↗ to jump to it; click again, ✕, or pick another character to see every speech. Nothing is flagged in the script or the status bar.
- Format Doctor: **Unclosed parenthetical** ("beat", "(beat" → "(beat)", formatting kept); **Consecutive character cue** (the same speaker twice with nothing between → **Merge speeches**; cues that already say (CONT'D), differ in extension, or are dual dialogue are left alone); **Missing time of day** for a heading that has INT./EXT. (**Add - DAY** on its own row; Fix All skips it). "Parenthetical without dialogue after it" is now **Dangling parenthetical**, and its Make Action fix drops the parentheses.
- Format Doctor: **Leading spaces** — Action that starts with spaces or tabs ("   Dave jumped up.") is flagged, and **Remove leading spaces** fixes it with bold / italic kept in place. Only the first line counts, so indented lyrics or letters further down a paragraph aren't flagged. A scene heading with spaces before it is now caught as **Scene heading format** (its fix already removed them). Nothing is trimmed while you type.
- A backup tip: when a script saved only in this browser reaches 10 pages (or 5,000 words), a small card in the bottom-right corner suggests linking a folder, with **Link Folder** (opens Projects on the Linked Folder card), **Dismiss**, **Don't show again** and ✕. It never takes focus and waits while another corner toast or Focus mode is showing. In browsers that can't link a folder (Safari, Firefox, phones and tablets) it offers **Backup Project** (a .draftline download, reopened with File → Open) instead, and comes back once the script has been saved 7+ days after its last backup (from the tip or the File menu). Safari adds a line about Add to Dock (Mac) or Add to Home Screen (iPad, iPhone), which stops Safari clearing the site after a week away; it's left out when DraftLine is already opened that way.
- Protected storage is requested automatically: after the first save with words in it (Chrome, Edge, Safari: silent, retried each session until granted), or in Firefox, whose request shows a permission bar, on the first Backup Project click (once). About's **Protected** line shows the result.
- Characters → Bios: a **Gender** picker (Male, Female, Non-Binary, Other, or not set) beside Age / Timeline, shown on the cue hover card and in the Story Bible PDF.
- Characters → Bios → **Populate Bio** (header, beside expand / close): reads each character's introduction in the Action (`MARJORIE (30s)--warm-dark skin, …`) and fills empty **Age / Timeline** (`30s`, `early 40s`, `mid-40s`, `50-something`), **Gender** (a word that names them first — `her female FRIEND (45)`, `--petite, amber-skinned woman`, `THEO (20s), her brother` — then the pronouns that clearly dominate; a stray "at him" for someone else doesn't count) and **Physical Description** fields, adding bios for speaking characters who don't have one yet. Fields with text or a choice are never changed, so it's safe to run again; Undo reverses it.
- Page breaks keep lead-in Action with what it introduces: a short line ending in a colon, a SUPER / INSERT / TITLE / CHYRON / PRE-LAP / "IN … WITH SUBTITLES" line, or a one-line all-caps line right before a cue or heading never ends a page (editor, Print and PDF). The Format Doctor flags anything still stranded at the bottom of a page, away from what it introduces: **Stranded at the bottom of a page** (no automatic fix).
- Anonymous in-app feedback: ⋮ → **Send Feedback…** (just above About DraftLine) asks which app you used before (optional), the missing feature keeping you from using DraftLine daily (required) and any details or bug notes (optional). It sends only those answers and a coarse OS name (Windows / macOS / Other) to DraftLine's feedback Worker (`VITE_FEEDBACK_ENDPOINT` overrides it at build time), with no cookies, no referrer and nothing from your scripts. A 4-second toast thanks you, or says it couldn't be sent and keeps what you typed.
- Find & Replace (Ctrl+F / Ctrl+H): a slim floating bar, highlights in the text (across page seams), match case, whole words, search one element type, Replace one or All (one undo step, snapshot first, formatting kept), a Find stepper in the status bar after closing; View Only allows Find only.
- Plan → Reports: Scenes, Characters, Locations and Script tables worked out from the script, sortable, each row a doorway (open the scene, spotlight the character, list a location's scenes), each exportable as .csv. Also ⋮ → Reports from Write.
- File → PDF opens **Export PDF**: **Include Scene Numbers (Production Draft)**, unchecked by default so the compiled PDF is an unnumbered spec script, then **Download PDF**. The choice is saved per script, and Print Script… (Ctrl+P) follows it through the print stylesheet with no dialog. The editor always shows scene numbers.
- Design notes for future work in `docs/specs/`: Table Read (local-first read-aloud) and Revision Mode.
- File → PDF: a PDF built inside DraftLine, off the main thread, with Courier Prime embedded — US Letter, 1.5 / 1 / 1 / 1 in margins, 54 lines a page, standard indents, page numbers from page 2, title page first, and the editor's page breaks including (MORE) / (CONT'D). Same bytes on every machine; no new dependencies.
- No-mouse writing: Tab in a Scene Heading moves on to the time of day (then down to Action); Tab on a Character name cycles (O.S.) → (V.O.) → (CONT'D) → none; Backspace on an empty non-Action line steps it back to Action before deleting.
- Smarter autocomplete: locations ranked by use, then recency; character names ranked by who speaks in the current scene, then the script, then Story Bible characters who haven't spoken yet.
- Export toast: every script export (.fountain, .fdx, .draftline, print / PDF) is confirmed bottom-right, closing itself after 8 s (paused while hovered or focused) without taking focus. At most every 14 days it adds a quiet Ko-fi / Patreon line with **Don't show again**.
- Format Doctor: a clean report (no findings, ignored ones included) can end with "Independent & ad-free · Support on Ko-fi · Patreon · Dismiss", at most every 30 days. Both callouts are throttled and permanently mutable per browser, and silent when localStorage is unavailable.
- Snapshot Compare: **Compare** beside each snapshot opens a read-only comparison with the current draft, Inline (red strike-through for deletions, green for additions, retyped elements tagged) or Side by Side. Element- and word-level Myers diff, run in a Web Worker; unchanged stretches fold away. Nothing is added to the writing canvas.
- Dialogue splitting across pages: a speech breaks when at least 2 dialogue lines fit on the page and at least 2 carry over, with a centred `(MORE)` at the foot of the page and `NAME (CONT'D)` at the top of the next. Never splits inside or directly after a parenthetical. You can type straight through the seam in the editor, and Print/PDF shows the same breaks.
- Per-element spellcheck: spellcheck and autocorrect on for Action, Dialogue and Centered; off for Scene Headings, Character cues, Parentheticals, Transitions and Format Cues.
- MIT license, linked from the About box footer.

### Changed

- The **Glossary** is now its own Story Bible tab: **DNA · Notes · Glossary**, with a book icon. DNA shows the story blueprint directly, so the Blueprint / Glossary switch is gone. The Glossary itself works exactly as before (search, three sections, Edit / Reset to starter text). Every ⓘ in DNA and Characters → Bios, and every Format Doctor chip, opens the Glossary tab at its term. The DNA tab keeps its name. The User Guide's Glossary section now follows Notes, and the README lists the three tabs.
- Every dropdown is now DraftLine's own (`components/Select.jsx`) instead of the browser's `<select>`, whose open list the operating system draws: Windows' bright blue highlight, its own font and square edges. That covers Element ▾, Characters → Bios (Primary Role, Secondary Function, Gender), Story DNA (Conflict type, + Add device…), the Find bar's Search in, Story Notes' Import into, and the Title Page's Title Font and Title Size.
  - **Look:** the File ▾ surface, an accent highlight on the active row, a ✓ on the current choice, hints in a right-hand column and titled groups. The closed Element control now reads just "Character"; the shortcuts moved to their own column. Title fonts show in their own face, with their note beside them.
  - **Keyboard and screen readers:** it works like a `<select>`: ↓ ↑ Enter Space Alt+↓ or a letter open it; arrows, Home / End and Page Up / Down move; Enter picks; Esc closes only the list; Tab moves on; typing jumps to an option. It follows the ARIA select-only combobox pattern.
  - **Element ▾ keeps the caret in the script** while you choose. Inside a dialog the list is drawn in the dialog, so it's never hidden behind one.
  - **Stored values are unchanged.** A test fails if a native `<select>` comes back. The Title Page's Credit and Draft suggestions are still the browser's own (`<datalist>`).
- Story DNA card titles drop their parentheses: **Complications** (was Rising Action (Complications)), **All Is Lost / Crisis** and **Climax / Resolution**. Their ⓘ tooltips and Glossary entries match: Complications, All Is Lost / Crisis, and Resolution / Falling Action, with the Craft section kept A–Z. Searching "rising action" still finds Complications. Question wording and storage keys are unchanged, so saved answers stay where they are. The Scene Board's Act 3 name, Climax & Resolution, is a separate label and is unchanged.
- Story DNA's Conflict picker groups the six conflict types under Robert McKee's three levels, as `<optgroup>`s: **Inner Conflict** (Individual vs. Self), **Personal Conflict** (Individual vs. Individual) and **Wider World Conflict** (vs. Society, Nature, Technology, Supernatural). The Glossary's Conflict / Obstacle entry nests the same six under **Inner**, **Personal** and **Wider World**, and its ⓘ tooltip groups them the same way. The stored values are unchanged, so saved scripts and loose spellings ("vs self", "Man vs. Nature") load exactly as before.
- Story DNA and the Glossary use screenwriting terms. Every saved answer, plot device and custom definition stays where it was.
  - **Blueprint questions:** "Why doesn't that work?" is now **Crisis (All Is Lost)** (it was labelled Climax, but it's the low point before the climax). "How does it end?" is now **Climax & Resolution**. Conflict / Debate is **Conflict / Obstacle** ("Debate" is a different Save the Cat beat), and Rising Action is **Rising Action (Complications)**. Each question keeps its storage key and wording, so existing answers stay under the same question; only the labels and their ⓘ links changed.
  - **Plot Devices:** **Ticking Clock** replaces Deus ex machina in the picklist. A script that already added Deus ex machina keeps its row, Yes / No and notes, and can still remove it.
  - **Glossary:** Climax now means the final confrontation, after the crisis. Falling Action is **Resolution (Falling Action)**. Deus ex machina reads as something to avoid. Conflict adds McKee's three levels (inner, personal, wider world). Catalyst notes Save the Cat's use of the word, after the original definition. New craft terms: **Crisis (All Is Lost)**, **Ticking Clock**, **Want vs. Need**, **Midpoint**, **Stakes**, **Setup & Payoff**, **B-Story** (57 terms in all). Renamed entries keep their ids, so a writer's own wording stays on the same entry.
- **View Only** is now **Viewing**, and its partner **Edit** is now **Editing**: the status bar badge names the mode you're in, not a button. Its tooltip says what a click does (**Switch to Viewing (read only)** / **Switch to Editing**), and the toasts, Element picker and Replace tooltips, keyboard shortcuts list, User Guide (the section is now **Editing and Viewing**) and README use the same words. Saved scripts still store it as `viewOnly`, so older scripts and backups open exactly as before.
- Top bar on smaller screens: Write and Plan now follow one rule.
  - **Element ▾ and B I U S move instead of disappearing.** Under 1200px they leave the bar together and sit in a row just above the script, in Page and Split (not Board or Focus), lined up with the script's gutter. That's what Plan's scene filter already did. Before, B I U S vanished under 1200px and the Element picker under 900px, leaving only keyboard shortcuts, so a tablet without a keyboard couldn't change element type or format at all. One shared fragment (`formatTools`) draws both copies, and CSS shows exactly one.
  - **Page | Split | Board turns to icons at the same width as Breakdowns | Stripboard | Reports** (under 900px; it was 768px), in one CSS rule.
  - **Below 440px, where the view switch leaves the bar, ⋮ now lists Page / Split / Board** with the current one marked Showing, as it already did for Plan's views. Before, Write's views were left on Alt+B only.
- Status bar steppers share one icon weight: the Dialogue stepper's speech bubble is now Lucide's MessageSquare (it was the drawer tab's own icon, which drew 1.75px thick, nearly twice the others), and the Format cross goes from stroke 1.5 to 1.75. Dialogue, Format, Density and Find are all Lucide at 14px and 1.75, about 1px of line each. The Characters drawer's Dialogue tab keeps its own bubble, to match the other tab icons.
- Snapshots: **Restore**, **Compare** and **Delete** fade in when you hover over a snapshot or Tab into it, so the list reads as dates and labels. They're always shown on the newest snapshot, on a card asking "Delete?", and on touch screens. The Delete? / Keep confirmation is unchanged.
- Characters → Bios: **Rename** and the ↑ ↓ order arrows fade in on row hover or keyboard focus (the arrows used to rest half-faded) and are always shown on an open bio and on touch screens. Both fades are opacity only: the buttons keep their space, so names and meta never shift, and they stay in the Tab order with their labels. While hidden they take no clicks (`pointer-events: none`), so a click on the empty spot does nothing; they take clicks again as soon as they show (hover, focus, an open bio, the newest or confirming snapshot, touch screens). No fade with reduced motion. The User Guide's Status bar, Scene Board, Plan filter, Breakdowns, Snapshots and Bios sections describe all six changes.
- Plan's scene filter shows its count once. Under 1500px, where the filter sits at the top of the Plan page, only its ✕ (**Clear the scene filter**) shows while a filter is set; the summary line right under it already says "4 of 53 scenes · … · filtered". In the header on wider windows it still reads **4 of 53 scenes ✕**.
- Plan → Breakdowns opens folded for scripts with more than 10 scenes, so a long script reads as a list of scenes to pick from (the header button reads **Expand All**); 10 scenes or fewer still open with every card open. It's decided once per script, the first time Plan opens for it (before the first paint, so there's no flash of open cards), and again when another script is opened. After that, Expand All / Collapse All and the single-card toggles work as before, and switching between Write and Plan keeps whatever you chose.
- Scene Board in Split view: act columns keep a 220px minimum (was 176px), so they no longer squeeze into slivers when Characters or Story Bible is open; past that the board scrolls sideways. Card headlines break only between words ("STATION / SIX", never "STATIO / N SIX") and are never hyphenated; only a single word too long for the whole line is split. A leading "1." in a headline is hidden when it repeats the number beside the card's grip. This is display only: the saved title keeps it, editing the headline puts it back, and a card moved to another position shows its number again.
- Status bar priority: as the window narrows, the bar now gives up low-priority items one at a time, from what it actually measures rather than from fixed breakpoints (`src/lib/statusFit.js`, `data-fit` 0–7 on the footer). The order is: keyboard hints first (hidden under 1400px and whenever a stepper is showing), then the scene / notes / word counts, then the Paper label (icon only), then Undo / Redo, then zoom − / + (the percentage stays). After that, stepper labels shrink to their arrows and count, and last of all Save and View Only show their icon without a label (the label stays as a tooltip and for screen readers). The element type, save state, Edit / View Only, page counter and every active stepper (Filter, Find, Format, Density) are never dropped. It refits when a stepper appears or the window resizes.
- Colour tokens for every interactive state (index.css): `--hover-bg` (one 4% white overlay for subtle hovers on any dark surface: toolbar and status buttons, B I U S, dropdown triggers, list rows; stacked on a resting fill where there is one, so hover still lightens it), `--border-hover`, `--accent-border` with `--accent-tint` / `-card` / `-field` (selected and open cards: the active project, the chosen storage destination, About's community cards on hover, open bios and glossary entries, export options), `--accent-soft` (on segments: B I U S, Plan's filters) and `--danger`. Header toggles keep two families, both from tokens: segmented switches ([Write | Plan], [Page | Split | Board]) select with the neutral chip, panel toggles (Story Bible, Characters) fill with the accent. Hardcoded whites on accent fills are now `--on-accent`. Hovers on the paper-coloured Scene Board and Snapshot Compare, and semantic colours (amber, notes yellow, danger), are unchanged. 24 files; `tests/colorTokens.test.js` fails if any of these states goes back to a hard-coded colour.
- Story Bible's top-bar button now matches Characters: outlined at rest and filled with the accent while its panel is open (it used the subtle grey chip). The two share the right-hand panel and switch each other off.
- Top bar spacing is one system. A single `--bar-gap` (22px, 18px under 1800px, 14px under 1650px …) sets the space between groups, and every divider sits exactly `--sep-space` (16px) from the nearest control on each side at every width (its margin adds only what the gap doesn't). Element ▾ has an explicit 12px before B I U S; B, I, U and S are 30px segmented targets 2px apart with uniform 4px 6px padding. A divider 16px after S closes the group (the same 16px as the divider before Element ▾) and stands in for the one before Page | Split | Board while the group shows; on the Board and in Reports the old divider returns, and Plan's scene filter closes the same way. Checked from 1920px to 768px, and at 1920, 1366 and 1024px in Write and Plan with Projects, Characters and the Story Bible open: nothing wraps, clips or truncates.
- View Only (status bar badge, Ctrl+Alt+L) is now saved with each script as `viewOnly` on its record: it survives reloads, switching scripts restores each one's setting, and it travels in .draftline backups and the linked folder (the newest copy wins on another computer). Scripts saved before this open editable; duplicates start editable. It stays separate from the Project Lock padlock (`isLocked`).
- Projects is easier to find: **File ▾ → Projects…** (Alt+P) is now the first item in the File menu, and the ▾ beside the title is a wider (28px), brighter button with a hairline divider. Title and ▾ share one outline on hover, while editing and while Projects is open, the tooltip reads "Projects (Alt+P)", and there's clearance before "by Author".
- The title in the top bar now sizes to its actual text, from 120px up to 512px on wide screens (448px under 1024px, 320px under 768px, unchanged on phones), so medium titles like "THE MIDNIGHT COURIER" show in full. When the bar is short of room the title shortens with "…" before any toolbar control is clipped.
- The status bar's save indicator has three states, named like Storage Destination: **App Storage Only** (hollow muted circle; click to link a folder), **Click to resume folder sync** (amber circle; click for the browser's permission prompt) and **Linked Folder Synced** (green dot). Saving no longer swaps the words for "Saving…": the dot pulses instead. "Not saved" and "Folder sync paused" still show when a save fails.
- File ▾: **Export Outline & Bible** is now **Export Planning & Production**, with **Scene Breakdown** (.csv) above Spreadsheet Outline: the same file as Plan's Export Breakdown, available from Write too. Plan's button now reads **Export Breakdown** (**Export** when narrow).
- Spreadsheet Outline (.csv): a card not linked to a scene takes its Scene Number from its title ("13. INT. …") or its place in the outline, and Heading drops the "13. " prefix (a title like "1986 coup" is left alone).
- Scene Board: **Populate from Script** is now **Import Scenes**, with a muted film-strip line icon; the same menu (Auto-Distribute, Manual Scene Ranges…).
- Projects → Storage Destination: the options are now **App Storage (Zero Setup)** ("Saves automatically inside DraftLine on this device. Start writing instantly. Export a backup before you clear your browser history.") and **Linked Folder (File Backup)** ("Saves .draftline files directly into your chosen computer folder, including locally synced cloud storage like Google Drive, Dropbox, or OneDrive.").
- Keyboard Shortcuts (Ctrl+/): Ctrl+P now reads **Print Script…** (the browser's print preview) instead of "Export Script (PDF)"; the compiled PDF download is File → PDF.
- File ▾ → Export Script now reads PDF (compiled) · Final Draft · Fountain · Print Script… (Ctrl+P); the other sections are unchanged.
- Enter at the end of a Dialogue line now ends the speech and starts Action (as in Final Draft) instead of another Dialogue line; Enter mid-line still splits a speech.
- Elements taller than a whole page break at the page edge (at least 2 lines each side) instead of running off the paper in print, and a heading above one stays with its first lines.
- Orphan prevention: a scene heading needs at least 2 lines of what follows on its page, or it moves to the next one. Transitions still never start a page.
- Long scripts run shorter where speeches used to jump whole to the next page and now split instead.

### Fixed

- ⓘ definition cards (Story DNA questions, Plot Devices, the Bios role pickers) and the **character cue bio card** in the script no longer open behind an open dropdown list (the Element ▾ list drops over the script on narrower windows). The browser draws a `<select>`'s list above the whole page, so a card opened under it was hidden. Cards now wait for a 350 ms hover instead of opening on contact, so the pointer passing over an ⓘ on its way to a dropdown doesn't flash one. They stay closed while any dropdown list is open (`src/lib/pickerGuard.js` follows native pickers through mouse, keyboard, change and focus events) and close on any click, as well as on scroll, resize and Escape. Keyboard focus still shows the card at once; clicking the ⓘ still opens the Glossary, without flashing the card first.
- Characters → Dialogue: the clickable **monologues** count no longer overlaps **Rename…** when the stats wrap onto two lines. It had a negative vertical margin that pulled it outside its row; it now sits inside it, and the rows are 8px apart.
- Plan on smaller screens (under 1500px): the scene filter and the summary line now share the column of the list below them. On Breakdowns they were 120px wider than the cards (1100px against 980px), so they started 60px further left; each view now sets one `--plan-w` (980px Breakdowns, 1100px Stripboard and Reports) that the filter, summary, cards, strips and reports all use, so the Find box sits flush with the cards' accent strip and nothing extends past the list.
- The same script could show different page counts and Density flags on two computers (96 vs 97 pages, 8 vs 10 skim risks), with a blank line under some paragraphs on one of them. When Courier Prime arrived from the network after the page was first laid out, lines were measured in the fallback Courier, whose slightly wider characters wrap a full 60-character line early, and were never measured again. Courier Prime now ships with DraftLine (the files the PDF already embeds, precached for offline use) instead of coming from Google Fonts, and every script line is measured again in one pass once it has loaded.
- Format Doctor no longer flags language directions kept as Action (`IN FRENCH WITH ENGLISH SUBTITLES:`, `IN CREOLE WITH ENGLISH SUBTITLES:`, `… SUBTITLED`, `IN CREOLE:`) as "Format cue tagged as Action". They can stay Action or be Format Cues; sequence cues such as `BEGIN FLASHBACK` are still flagged.
- Right-click on script text is never redirected: the sheet's click-to-nearest-line handler and the page-seam caret routing now act on the left button only, and every layer over the text is click-through, so the browser's own menu (spelling suggestions, Add to dictionary) opens on the word under the pointer. A chosen suggestion is an ordinary edit: it updates the script and is undoable with Ctrl+Z.
- Scene Board drag-reorder stopped moving scenes in the script after **File → Import… → Load into Editor**: the import gave every element a new id and left the scene cards pointing at the old ones, so a drag only moved the board. Scene cards now follow their headings into an imported script (in the same Ctrl+Z step), boards already left unlinked mend themselves when the project opens, and every drag checks the links first.

### Notes

- `(MORE)` and `(CONT'D)` are layout only. They never enter the script data, Fountain, Final Draft or `.draftline` exports.
